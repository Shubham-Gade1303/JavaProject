	Can constructor be final?
--> No, constructor can not be final 
	A final keyword is used to privent inhiretance related modification 
	A final method can not be overridden
	A final method can not be inhiretated
	A final variable cannot be reassinged
	A constructor is never inherited,

	marking a constructor final has no meaning.

	Difference between Constructor and Method?
    constructor:- 
		constructor is used to initilize an object when it is created 
		constructor must be same name as class name,
		constructor can't have return type or not even void
		it automatically called when object is created
		constructor can be overloaded
		constructor can not be overloaded
		constructor are not inhiretated 
		compiler provide default constructor if you are not created

    vs
    methods:- 
		methods are used to perform the sprecific task
		methods can have any valid name 
		methods have return type(int, void, String)
		method called explicitly when object called
		methods can be overloaded
		methods can b overridden (expect static , final, private);
		method are inhiretated(unless private)
		no default method are created by the compiler

		}

		}
